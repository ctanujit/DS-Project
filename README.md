This is the GitHub repository for the **MATH175-Active Science Project course** for L1 Mathematics (Semester 2) students at *Sorbonne University Abu Dhabi*. 

In this course, Dr. Tanujit Chakraborty will teach you (along with Hands-on-sessions in Python):
1. Introduction to Data Science
2. Descriptive Statistics
3. Correlation Analysis
4. Linear Regression Methods (Ridge, LASSO)
5. Nonlinear Regression (Polynomial and Simple Neural Networks)
